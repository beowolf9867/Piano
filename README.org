** My setup
*** Construction
1. The Multiplexers (4 x CD4051BE)
   1. Place all four chips in a row on your breadboard. Each chip has 16 pins.
      1. Power & Enable (Shared): Pin 16 (VDD): All to 3.3V.
         1. Pins 6 (INH), 7 (VEE), 8 (VSS): All to GND
      2. Address Selection (Shared): Pin 11 (A): All to PCO
         1. Pin 10 (B): All to PC1.
         2. Pin 9 (C): All to PC2.
      3. Common Signal Output (Unique):
         1. MUX 1 Pin 3 → PA0.
         2. MUX 2 Pin 3 → PA1.
         3. MUX 3 Pin 3 → PA2.
         4. MUX 4 Pin 3 → PA3.
      4. Inputs (Pins 13, 14, 15, 12, 1, 5, 2, 4):
         1. Connect to your keys.
            1. MUX 1 handles Keys 1–8,
            2. MUX 2 handles 9–16
2. The Analog Charge Path (The 10MΩ Resistors)
   1. The Driver: Connect PC3 of the il matto to a long "rail" (a row) on the breadboard.
   2. The Resistors: Take 25 resistors. Plug one end of every resistor into that PC3 rail.
   3. The Junction: The other end of each resistor must connect to two things:
      1. The flexible wire going to the specific Copper Key.
      2. The specific Input Pin on the Multiplexer for that key.
3. The Audio Output
   1. Connect PD7 to a 100Ω resistor.
   2. Connect the other end of that resistor to the "Tip" of your headphone jack.
   3. Connect the "Sleeve" of the headphone jack to GND.
*** C-Code
1. Function One: ~Initialize_System~
   1. Configure the ATmega644P hardware registers.
      1. Set PORT C pins 0, 1, 2 (Address) and 3 (Driver) as Outputs.
      2. Set PORT D pin 7 as an Output (for PWM).
      3. Initialize the ADC (il matto Ref 2.3): Set the voltage reference to AVCC and the prescaler to 64 (this slows the ADC down to a readable frequency).
      4. Initialize Timer 2 (il matto Ref 2.5): Set it to Fast PWM mode. This creates the high-frequency carrier for your sound.
      5. Initialize Timer 0: Set it to trigger an Interrupt (ISR) roughly 20,000 times per second.
2. Function Two: ~Audio_Mixer_Interrupt~ (The ISR)
   1. Create polyphonic sound in real-time.
      1. Create a "Sum" variable starting at zero.
      2. Loop through all 25 keys. If a key is marked as "Active":
      3. Update that key's Phase Accumulator (add its frequency value to its current position).
      4. Look up the volume level from your Wavetable using that phase.
      5. Add that level to the "Sum".
      6. Divide the "Sum" by the number of active keys (this prevents the sound from distorting).
      7. Write the final result to the OCR2A register. This physically moves the speaker diaphragm to create the wave.
3. Function 3: ~Measure_Key_Capacitance~
   1. Perform RC timing
      1. Set the A, B, C pins on PORT C to the address of the key you want.
      2. *Discharge*: Set the corresponding ADC pin (PA0-PA3) to a digital Output and drive it LOW for 10 microseconds. This empties the "capacitor" (the copper key).
      3. *Charge*: Switch that ADC pin to an Input (it now acts like a voltmeter).
      4. *The Pulse*: Turn PC3 (Driver) to HIGH. Electricity starts flowing through the 10MΩ resistor to the key.
      5. *The Delay*: Wait for a very specific time (approx. 5 to 8 microseconds).
      6. *The Measurement*: Trigger the ADC conversion immediately.
      7. *The Result*: Return the 10-bit number. If someone is touching the key, the number will be lower because the key charged up slower.
4. Function 4: ~Calibrate_Piano~
   1. Establish "Baseline" values for a quiet room
      1. Wait 1 second after power-up.
      2. Run the ~Measure_Key_Capacitance~ function 10 times for every key.
      3. Store the average value for each key in a "Baseline Array." This is the "Untouched" state.
5. Function 5: ~Main_Execution_Loop~
   1. The infinite loop that scans the keyboard.
      1. Run ~Calibrate_Piano~ once.
      2. Start a ~while(1)~ loop:
      3. For each of the 25 keys, call ~Measure_Key_Capacitance~.
      4. Compare the result to that key's stored Baseline.
      5. If the value is less than 90% of the baseline, mark that key as Active in a global array.
      6. Otherwise, mark it as Inactive.
      7. The ~Audio_Mixer_Interrupt~ will automatically see these "Active" marks and start playing the notes.
